# Service ROS bridge

> **Status:** Just an idea. No ROS code here.

Run .service precheck files (fitzyracing1/service) on wheeled robots through ROS, triggered by sensors, before any API call or uncertain movement.

## Where this came from

This idea came up in a chat with one of Joshua Almeida's bots (Service bot, Oct 11 2026) and was not taken further at the time. This repo records it so it can be picked up later.
